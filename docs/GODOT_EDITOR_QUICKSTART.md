# Godot 4 编辑器操作速查（本项目专用）

> 目标：够你用最短时间恢复手感，覆盖我们搭建 Alchemy 场景要碰到的**所有操作**。
> 不用背，遇到不会的动作来这里查。

---

## 0. 界面认识（四个面板）

```
┌──────────────────────┬───────────────────────┬──────────────────────┐
│  文件系统 (左下)       │   2D 视口 (中间)        │   Inspector (右侧)    │
│  · 项目的所有文件       │  · 场景的可视编辑区      │  · 选中节点的所有属性    │
└──────────────────────┴───────────────────────┴──────────────────────┘
┌──────────────────────────────────────────────────────────────────┐
│  场景 (左上)：当前场景的节点树（父子层级）                           │
└──────────────────────────────────────────────────────────────────┘
```

- **场景面板**（左上）：看节点树、选节点、加子节点、拖拽调整父子关系
- **视口**（中间）：可视化摆放/查看
- **Inspector**（右侧）：改选中节点的属性、挂脚本、拖引用
- **文件系统**（左下）：建文件夹、建场景文件、拖资源进项目

> 大多数操作围绕"**先选中节点 → 再改右侧 Inspector**"。

## 1. 标准流程：搭一个场景（我们每次都用这套）

搭主菜单、地图、战斗场景，全是同一套动作：

| 步骤 | 操作 | 快捷键 |
|---|---|---|
| ① 新建场景 | 顶部菜单 **场景 → 新建场景**；弹窗里选根节点类型（我们多用 `Control`） | |
| ② 加子节点 | 在**场景面板**选中根节点 → 右键 → **添加子节点**（或点工具栏 ＋ 图标） | `Ctrl+A` |
| ③ 选节点类型 | 弹窗里搜索类型名（如 `Label`、`Button`），选中 → 创建 | |
| ④ 重命名 | 场景面板里选中节点 → 按 **F2**，改名（我们脚本认名字，别乱改） | `F2` |
| ⑤ 改属性 | 选中节点 → **Inspector** 右侧改（Text 文字、锚点、Visible 等） | |
| ⑥ 挂脚本 | 选中**根节点** → Inspector 顶部**脚本栏 `<空>`** → 新建/加载 | |
| ⑦ 拖引用 | Inspector 出现 Export 字段 → 从**场景面板**把节点拖进字段 | |
| ⑧ 保存 | `Ctrl+S`；保存位置选 `scenes/对应子目录/xxx.tscn` | `Ctrl+S` |

**运行看效果**：`F6`（直接跑当前打开的场景）；`F5`（从主场景跑整个游戏）。

## 2. 常用节点类型（我们只用这些）

| 类型 | 用途 | 关键属性 |
|---|---|---|
| `Control` | 所有 UI 的根/容器基类（我们场景根都用它） | Layout → Anchors |
| `Label` | 显示文字（标题、状态栏、按钮上的字） | `Text`、`Theme Overrides → Font Size` |
| `Button` | 可点击按钮 | `Text` |
| `LineEdit` | 单行输入框（种子输入） | `Placeholder Text` |
| `HBoxContainer` | 子节点**横向**自动排列 | （容器自动排版，别手动调位置） |
| `VBoxContainer` | 子节点**纵向**自动排列 | 同上 |
| `CenterContainer` | 子节点**居中** | 同上 |
| `PanelContainer` | 带底色的面板（房间结算弹窗） | 勾掉 `Visible` = 默认隐藏 |
| `Node2D` | 2D 无 UI 节点（地图动态层，代码放东西用） | |

> **容器规则**：放进 `HBox/VBox` 的按钮、标签会自动排队，**不需要、也不应该手动拖位置**。要调间距就选中容器，Inspector 搜 `separation`（Theme Overrides → Constants → Separation）。

## 3. Inspector 高频操作

- **改文字/字号**：选中 Label/Button → Inspector → `Text` 改文字；`Theme Overrides` → `Font Sizes` → `Font Size` 改字号
- **锚点**（决定控件贴屏幕哪里）：选中 Control 类节点 → `Layout` → `Anchors Preset` 下拉
  - `Full Rect` = 铺满全屏（如居中容器）
  - `Top Wide` = 贴顶部拉满（如状态栏）
  - `Center` = 居中
- **默认隐藏**：选中 → 取消勾选顶部 `Visible`
- **位置/尺寸**：`Position`（坐标）、`Custom Minimum Size`（最小尺寸，按钮用）
- **改颜色**：`Modulate`（节点整体染色）

---

## 4. 挂脚本 + 拖引用（最容易卡的一步）

1. **选中要挂脚本的节点**（一般挂场景根节点）→ Inspector **最上方**脚本栏显示 `<空>`
2. 点脚本栏 → **加载** → 选择 `res://src/Nodes/xxx.cs`（脚本我已写好）
3. 挂好后，Inspector 里会出现脚本的 **Export 字段**（灰底小方块）
4. **从左侧场景面板把对应节点拖进字段**（比如把 `StartBtn` 拖进 `StartBtn` 字段）
5. 漏拖会怎样？运行后在**底部输出面板**报 `漏拖 xxx`——照提示补拖即可

> 提示：Godot 的脚本用 `[Export] private Button _startBtn = null!;` 声明，字段名就是我们在代码里写好的，拖的时候按名字对号入座。

## 5. 项目设置（配一次就基本不用碰）

顶部菜单 **项目 → 项目设置**：

| 设置 | 位置 | 我们怎么用 |
|---|---|---|
| 主场景 | `运行 → 主场景` | 指向 `main_menu.tscn`（建好主菜单后切） |
| Autoload 单例 | `全局 → Autoload` | **已配好 GameState，不用动**（打开可看到） |
| 中文字体 | 搜 `theme` → `Gui → Theme → Custom` | 新建 Theme，Default Font 里放中文字体（否则中文变方块） |

## 6. 运行 / 构建 / 排错

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 构建（编译 C#） | `Ctrl+B` | 改了 `.cs` 后要重新编译 |
| 运行当前场景 | `F6` | 不经过主菜单，直接跑你打开的场景 |
| 运行整个项目 | `F5` | 从主场景开始 |
| 停止 | `F8` | 退出运行 |
| 看报错 | 底部 **输出 (Output)** 面板 | `PushError` 的"漏拖 xxx"会打这里 |

> ⚠️ 改了 C# 脚本后：先 `Ctrl+B` 编译，再 `F5`/`F6` 运行；偶尔改完脚本运行没生效，**关闭并重开编辑器**强制重编译最省事。

## 9. 本项目常见坑（记住这几点少踩雷）

1. **根节点类型**：主菜单/地图/战斗用 `Control`（不是 Node2D）——脚本继承自 Control
2. **中文字体**：不配字体 = 所有中文显示成方块（第 5 节）
3. **容器别手动拖**：放进 HBox/VBox 的子节点由容器排版，手动拖位置会被拉回去
4. **节点名别乱改**：脚本 Export 字段拖引用后，改名字引用不失效（引用按对象走），但重搭时记得按蓝图命名
5. **漏拖引用**：运行时输出面板会报 `漏拖 xxx`，按提示补拖，别慌
6. **改了脚本不生效**：先 `Ctrl+B`；不行就关编辑器重开
