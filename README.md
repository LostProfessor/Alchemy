# Alchemy · 炼药肉鸽

> 类《杀戮尖塔》的肉鸽爬塔，但你不是在打牌——**你在锅里炼药**。
> 选一种基底，把带词条的药材按该基底的规则丢进锅里计时调制，出炉的药水拖到敌人身上砸出去。

**状态**：可玩原型（1–5 层全流程可通关）· Godot 4.6.2 (.NET) + C# · 逻辑层 219 个单元测试全绿 · 界面支持 简体中文 / English

---

## 一句话玩法

战斗是"实时时间轴 + 回合意图"的混合：敌人排在倒计时条上蓄力出手，你在同一条时间轴上**炼药、投掷、并抓时机破招**——在敌人出手前的那一瞬间把伤害打进去，就能直接打断它。

## 核心循环

```
地图选房间 → 战斗 / 事件 / 宝箱 / 商店 / 火堆
   → 战斗胜利：三选一奖励袋（药材 / 货币 / 遗物）
   → 层末首领战 → 三选一「首领遗物」→ 进入下一层（共 5 层）
   → 通关 / 倒下（整局归档进「历史回顾」）
```

## 玩法与系统

### 1. 炼药引擎（本作核心）

- **三种基底 = 三套炼药规则**：清水（队列，按加入顺序结算）、浓油（栈，后进先出）、黏液（反转，顺序颠倒）。
- 药材并非"直接生效"，而是**往锅里写入操作**：添加/移除某个效果、去掉末尾、翻转顺序、反转极性（增益 ↔ 减益互换）。
- 工作台 5 格，逐层累积；成锅后以**计时动作**调制（当前 2 秒加料 / 3 秒完成，数值在 `content/settings/brewing_settings.tres` 里可改，不动代码即可调平衡）。
- 出炉药水的颜色由锅内内容混合生成，可拖到**敌人**（攻击/削弱）或**玩家区**（治疗/增益）投掷；药水**不跨战斗保留**，一场战斗结束清锅。

### 2. 药材与口袋

- 16 种药材 × 4 个稀有度，每株都带"增减效果"词条；悬停显示描述与逐条效果增减（增益绿 / 减益红）。
- 药材是**一次性消耗品**，存放在随整局累积的"口袋"里，炼药时直接取用。
- 补充方式：战斗后**三选一奖励袋**（实现上保证三个袋子的内容不会完全一致）。

### 3. 效果系统

- 20 余种效果，区分增益/减益极性，可叠层数、可带剩余时长；瞬时效果与持续效果分流处理。
- 抗药性 / 涤净 / 加深 / 消解组成了"下药策略"：用错剂量会被抗药性吃掉，得先涤净再灌。

### 4. 战斗与破招（招牌机制）

- 敌人意图排在时间轴上倒计时，**出手前有预兆（telegraph）**：默认提前 1.5 秒，可打断的招式提前 2.5 秒，且每个意图都能单独配置。
- **破招**：在预兆之后、结算之前，对可打断的意图造成 ≥ 阈值的伤害即可打断——敌人瘫痪 2 秒并跳过这一招（连 DoT 的伤害都能卡时机拿来破招）。
- 表现层订阅 `ActionTelegraphed` / `ActionInterrupted` 两个事件播抬手与瘫痪动画；UI 上可破招的意图带 `⚠` 警示色，瘫痪显示 `💫 瘫痪`。

### 5. 遗物

- 16 件遗物：被动=监听战斗钩子（开战给格挡、给敌人上状态…），主动=每场限次（如法力水晶每场回血 1 次）。
- 获取：开局三选一、精英战额外掉落、层末**首领遗物三选一**（跨层使用）、事件与商店。

### 6. 地图与房间

- 《杀戮尖塔》式分支地图；静态放置规则保证精英/商店/宝箱/休息点互不相邻。
- 房间类型：战斗 / 事件 / 宝藏 / 商店 / 火堆 / 首领。地图上的"?"事件点进房时会**分流**（约 7% 变常规战斗、7% 变宝箱、7% 变商店，其余才是真事件）。
- **火堆**：睡觉回血（遗物可加成）或探索换普通遗物 + 药材。
- **商店**：3 件遗物（第 1 件保底普通）+ 5 个药材袋（5–10 株、混合稀有度），单价按稀有度区间浮动。
- **宝箱**：货币 / 遗物 / 药材袋**逐块可领、可跳过**，与战斗奖励面板的交互一致。

### 7. 整局、存档与回顾

- **确定性随机**：一局由主种子派生（战斗、奖励、地图分流各自独立随机流），同种子可复现。
- JSON 状态存档，**房间即检查点**（战斗中退出 → 重进该房间重打）；还专门实现了"在奖励界面存档/读档"的恢复（连首领遗物三选一都能续上）。
- 主菜单可"继续"，设置页可"保存并退出到主菜单"（保留存档）；一局结束（通关/倒下/放弃）会**归档进历史并删除进行中存档**，「历史回顾」场景按时间线展示每一局的经历。
- 地图上的"回主菜单" = 放弃本局，带复核确认弹窗。

## 操作

- 拖药材进锅 → 点【完成制作】→ 药水出炉 → 把药水拖到敌人或自己身上投掷。
- 顶栏显示大层/房间、生命/护盾、货币、口袋数量、本场战斗计时与整局总时长；地图上的"口袋"按钮可查看材料清单。

## 技术设计

- **分层**：`src/Alchemy.Core`（纯 C# 逻辑库，零 Godot 依赖，可单元测试）↔ `src/Nodes/**`（Godot 表现层）↔ `tests/Alchemy.Core.Tests`（xUnit）。表现层只做显示与输入，规则与状态都在逻辑层。
- **数据驱动**：`content/**/*.tres`（药材、遗物、敌人、遭遇表、事件、职业、平衡数值）由 `ContentCatalog` 扫描后注入逻辑层目录，缺资源时回落到逻辑层的硬编码默认值。
- **钩子系统**：逻辑层用中央 `HookHub`/`IHookListener`（可修改参数、触发顺序确定），表现层用 Godot 信号——两层互不污染。
- **统一时间轴**：战斗推进、炼药计时、瘫痪、预兆都走 `CombatState.AdvanceTime`。
- **本地化**：中文源串即 msgid，`localization/translations.csv` + 生成的 `translations.en.translation`；控件直接赋值的文本由 Godot 自动翻译，拼接/格式化文案走 `src/Nodes/L.cs` 的 `L.T` / `L.F`。
- **设置**：音量（主/音乐/音效）、帧率上限、语言，持久化到 `user://settings.json`，改动即时生效。

## 运行与构建

环境：Godot **4.6.2 (.NET/mono 版)** + .NET SDK 9

```bash
# 逻辑层编译 + 单元测试
dotnet build Alchemy.sln -t:Rebuild
dotnet test tests/Alchemy.Core.Tests --nologo

# 无头冒烟（不弹窗口，跑 120 帧后退出）
"<Godot 可执行文件>" --headless --path . --quit-after 120

# 资源重新导入（改了 .tres / translations.csv 之后）
"<Godot 可执行文件>" --headless --path . --import
```

用 Godot 编辑器打开 `project.godot` 后按 <kbd>F5</kbd> 即可运行；场景（`scenes/**`）在编辑器里搭建，脚本只负责逻辑与内容填充。

## 目录结构

```
Alchemy/
├── src/Alchemy.Core/     # 纯逻辑层：炼药引擎、战斗、效果、遗物、地图、房间、存档、随机
├── src/Nodes/            # Godot 表现层脚本（挂到 scenes/** 的节点上）
├── scenes/               # 场景：主菜单/职业选择/开局/地图/战斗/房间/设置/历史/结算/UI 预制体
├── content/              # 数据资源 .tres：药材、遗物、敌人、遭遇表、事件、职业、平衡数值
├── localization/         # 翻译表（translations.csv → translations.<locale>.translation）
├── tests/Alchemy.Core.Tests/  # xUnit 单元测试（219 个）
├── Theme/                # 主题、字体、UI 贴图
├── docs/                 # 美术清单、Godot 集成与编辑器速查等开发文档
└── tools/                # 开发辅助脚本
```
